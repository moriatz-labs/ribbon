# __APP_TITLE__ Agent Contract

This application was generated by Ribbon. `ribbon.json` is authoritative for its selected DNS, backend, deployment, mail, and design-system adapters. Follow the Ribbon control-plane workflow for provider linking, release work, and URL handoff.

## Provider contract

- Do not replace a provider by changing imports or workflow commands in isolation. Change the manifest selection, regenerate or apply the matching adapter files, and run `ribbon check`.
- The backend adapter owns session, records, and storage through `src/lib/backend.ts`. Product UI must depend on that contract rather than importing Supabase or Firebase directly.
- Supabase projects keep migrations, explicit Data API grants, RLS, private Storage policies, and SQL policy tests. Firebase projects keep owner-scoped `firestore.rules` plus `firebase.json`; they add `storage.rules` only when the manifest explicitly selects `storage: "cloud-storage"`.
- `pnpm dns` reads the selected DNS and deployment adapters from `ribbon.json`. Hostinger and Cloudflare updates reject conflicting record types; Cloudflare records stay DNS-only.
- The generated GitHub workflow must match `providers.deployment.provider`. Vercel, Netlify, and Firebase deployment credentials stay server-side and production releases occur only through reviewed GitHub Actions.
- Hostinger Mail is a separate optional capability. When selected, keep magic-link generation, database rate limiting, and delivery server-side. Otherwise use backend-managed authentication email.

## Non-negotiable Strawn contract

- Resolve Strawn from npm using the exact version in `ribbon.json` and `package.json`.
- Import generic primitives and providers from the public `strawn` root and icons from the public `strawn-icons` root.
- Keep product-specific composition in this app. Tailwind, shadcn/ui, Lucide, direct Radix imports, and inline SVG icons are forbidden.
- Keep `strawn` and `strawn-icons` exactly pinned and keep `projectType: "application"`.

Before release, run `pnpm check`, run `pnpm ribbon check <this-project-path>` from Ribbon, execute the selected backend's policy tests, provision DNS through the selected adapter, and release through a pull request.

Never expose service-role/admin credentials, Hostinger or Cloudflare tokens, Vercel or Netlify tokens, Firebase service-account credentials, or private deploy keys in browser-prefixed variables.
